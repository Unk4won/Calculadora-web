**Descripción:** Realiza operaciones basicas (suma, resa, multiplicacion, division) con una interfaz intuitiva y accesible desde cualquier navegador.

## ✨ Características

- **Operaciones matemáticas completas:** Suma, resta,
  multiplicación y división funcionales
- **Display de resultado:** Muestra el número ingresado y
  el resultado final en tiempo real
- **Botón de limpiar (C):** Reinicia la calculadora
  para nuevos cálculos
- **Validación de errores:** Previene división por cero
  con mensaje de error
- **Interfaz responsiva:** Se ve perfectamente en celular,
  tablet y computadora
- **Diseño intuitivo:** Botones organizados como calculadora
  tradicional, fácil de usar

## 🚀 Instalación

### Requisitos Previos

- Navegador moderno (Chrome, Firefox, Safari, Edge)
- Editor de texto o IDE (VS Code recomendado)
- Git instalado (opcional, para clonar)

### Pasos

1. **Clonar o descargar el repositorio**

```bash
   git clone https://github.com/Unk4won/Calculadora-web.git
   cd calculadora-web
```

2. **Abrir el proyecto**
   - Abre `index.html` directamente en tu navegador
   - O usa una extensión como "Live Server" en VS Code

## 💻 Uso

**Ejemplos de uso**

```
1. Ingresa el primer número
2. Selecciona la operación (+, -, *, /)
3. Ingresa el segundo número
4. Presiona el botón "="
5. Verás el resultado
```

### Casos de Uso

- Caso 1: Realizar operaciones básicas
- Caso 2: Limpiar la pantalla
- Caso 3: Manejar errores
